\# CFG–CNF–CYK Visualizer



Ứng dụng web chuyển đổi văn phạm phi ngữ cảnh CFG sang dạng chuẩn Chomsky CNF và trực quan hóa từng bước thuật toán CYK.



\## Công nghệ dự kiến



\- Python và Flask

\- HTML, CSS và JavaScript

\- Docker

\- GitHub



\## Chức năng chính



\- Nhập và kiểm tra cú pháp CFG.

\- Chuyển đổi CFG sang CNF.

\- Kiểm tra chuỗi bằng thuật toán CYK.

\- Trực quan hóa bảng CYK theo từng bước.

\- Dựng cây phân tích cú pháp.
